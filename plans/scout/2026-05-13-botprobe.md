## Original: CloakBrowser
A stealth browser built on Playwright that passes bot-detection systems by masking headless browser signals and fingerprinting vectors.

## Twist: BotProbe
**Concept:** A CLI tool + local web dashboard that audits your own website's bot-detection posture. It runs a battery of automation probes against a URL you own and produces a scored report showing which fingerprinting signals are leaking, which rate-limit thresholds can be found, and which detection checks pass or fail — helping developers harden their anti-bot defenses rather than bypass them.

**Target user:** Web developers and security engineers who want to verify that their anti-bot measures (Cloudflare, custom CAPTCHAs, fingerprinting middleware) actually work before attackers exploit gaps.

**Core differentiator:** CloakBrowser is an offensive tool that evades detection. BotProbe is a defensive audit tool that tests detection effectiveness from the inside — you point it at your own domain, it uses the same evasion techniques as CloakBrowser to probe for weaknesses, and it tells you what it found. No paid APIs; all probes run locally via Playwright and headless Chromium.

**Suggested stack:** Python + SQLite — Python has the best Playwright bindings, SQLite stores scan history and probe results locally with no infrastructure needed, and a lightweight FastAPI server serves the optional local dashboard. CLI-first, dashboard is a bonus.
