# MISSION.md — cf4-autofill

## What This Builds

A web tool for Philippine importers and exporters to auto-fill the Bureau of Customs (BOC) Customs Form 4 (CF4). Users build and save importer/exporter profiles, auto-populate CF4 fields from a saved profile, enter line items, get AI-assisted HS code suggestions via Claude Haiku, and export a submission-ready PDF. The PDF matches the official BOC CF4 field layout exactly.

## Primary Users

Philippine importers, exporters, customs brokers' assistants, freight forwarders, and small business owners who regularly file CF4 declarations and want to reduce manual data entry errors.

## In Scope

- Importer and exporter profile builder (TIN, business name, address, contact)
- Auto-population of CF4 fields from a saved profile
- Line-item entry (description, quantity, unit of measure, declared value, currency)
- AI HS code lookup via Claude Haiku (inference-based, with mandatory disclaimer)
- PDF generation server-side (PDFKit or Puppeteer) matching official BOC CF4 layout
- Export to PDF ready for BOC submission
- Free tier: 3 saved profiles, 10 exports/month
- Pro tier ($4.99/mo): unlimited profiles, unlimited exports, batch CSV import of line items
- Stripe billing

## Out of Scope

- Third-party HS code databases or paid tariff APIs (AI inference only)
- Electronic filing or direct submission to BOC systems
- Customs duty calculation or tariff rate lookup
- Support for other BOC forms (Import Entry, Export Declaration, etc.)
- Native mobile apps (Capacitor shell is web-only PWA)
- Integration with freight or logistics platforms
- Multi-user or team accounts
- Document OCR or auto-extraction from existing forms

## Immutable Constraints

1. **AI HS code disclaimer is mandatory and permanent.** The text "HS codes generated by AI are not legally binding. Verify with a licensed customs broker." must appear on every HS code suggestion in the UI and on every exported PDF. Agents must never remove, shorten, or conditionalize this disclaimer.
2. **CF4 form field layout matches official BOC CF4 format exactly.** Agents must not change the field layout, field names, or field order in `api/src/cf4-template/` or `app/src/components/CF4Form.vue` without explicit human approval.
3. **PDF generation is exclusively server-side** in `api/src/pdf/`. Agents must not generate PDFs in the frontend.
4. **Import/export manifests are not retained beyond 90 days** for free tier users. Pro users may retain indefinitely.
5. **Pro pricing is hardcoded at $4.99/month.** Agents must never alter Stripe pricing constants or price IDs.
6. **Claude API is called exclusively from the NestJS backend** — never from the frontend.
7. **Protected component `app/src/components/CF4Form.vue`** — form field layout cannot be changed by agents without human approval.
