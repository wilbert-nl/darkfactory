## Recommended Starting Point

**Build NearAlert first.** The Manila commuter problem is real, emotionally urgent, and experienced by millions of Filipinos every single day. The MRT/LRT lines carry hundreds of thousands of passengers daily and falling asleep past your stop is not a niche edge case — it is a universal commuter experience. This gives NearAlert a built-in viral distribution mechanism: the moment one person uses it on the MRT, the person next to them asks what it is. The technical build is straightforward (geofence + background location + alarm, NestJS backend optional for the MVP), legal risk is low (standard iOS/Android background location consent), and there are no strong Philippine-specific competitors. Most importantly, this is a product you can explain in one sentence, ship in three weeks, and grow through local social media without a marketing budget.

**Run CF4Autofill as your second build in parallel.** While NearAlert builds consumer traction and proves your ability to ship, CF4Autofill is a B2B revenue machine with zero competition and a captive audience of 7,000 licensed customs brokers in the Philippines who currently fill out CF4 forms manually. A well-positioned SaaS tool at ₱2,000–₱5,000/month per broker hits $120K–$480K ARR with a small customer base. The NestJS + Vue stack is perfect for a form-automation + PDF-generation workflow, and Claude can handle the bulk of the boilerplate. These two products together give you consumer virality (NearAlert) and B2B cash flow (CF4Autofill) — the ideal solo founder combination.

## Quick Wins (Build in < 4 Weeks)

These five ideas can each reach an MVP within four weeks using NestJS + Vue 3 + PostgreSQL and Claude:

1. **NearAlert** — Geofence alarm app; core logic is a location listener + push notification; mobile-first with a minimal backend.
2. **SongVote** — QR code → real-time vote tally; purely a Vue 3 frontend + WebSocket backend; no auth required for MVP.
3. **CommentsReader** — Browser extension + simple TTS API call; zero backend required; ship as a Chrome extension in under a week.
4. **CompareTable** — Pure frontend with optional user auth for saving comparisons; Vue 3 + local storage MVP is a weekend project.
5. **ProConAid** — Weighted decision matrix UI; stateless frontend MVP takes 2–3 days; add auth + persistence for paid tier in week two.
