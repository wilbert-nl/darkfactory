# GIF Search Tool for Social Media Managers

## Tagline
Find, preview, and schedule the perfect reaction GIF for every post — without leaving your content calendar.

## Target Market
Social media managers and content teams at agencies and SMBs managing multiple brand accounts across platforms.

## Problem
Social media managers spend disproportionate time context-switching between Giphy, their scheduling tool, and brand guidelines just to find an appropriate GIF. There is no tool that combines GIF search, brand-safe filtering, and direct export to scheduling platforms in one workflow. Using off-brand or tone-inappropriate GIFs is a recurring risk when teams work fast.

## Solution
A focused GIF search interface powered by the Giphy API with brand-safety filtering, team favorites libraries, and one-click copy or export to Buffer/Hootsuite-compatible formats. Teams can tag GIFs, build a curated brand library, and pull from it without searching Giphy from scratch each time.

## Core Features (MVP)
- Giphy-powered keyword search with content rating filter (G, PG, PG-13)
- Team brand library (save and tag approved GIFs)
- One-click copy of embed URL, direct link, or download
- Collections organized by campaign or platform
- Usage history log per team member

## API Used
- Giphy API — GIF search, trending GIFs, and direct media URLs with rating metadata

## Monetization
Team SaaS — $25/month per team (up to 5 seats); $59/month (up to 20 seats + brand library + usage analytics).

## Tech Stack Suggestion
Next.js + Supabase + Tailwind CSS + Resend (weekly trending digest).

## MVP Scope
Included in v1: GIF search, content rating filter, brand library with tagging, URL/download export, collections, usage history.
Out of scope: direct posting to social platforms, AI-suggested GIFs, video clip support, Slack integration, approval workflows.
