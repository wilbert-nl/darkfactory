# Dictionary Lookup Tool for Content Writers

## Tagline
Look up definitions, pronunciation, and usage examples without leaving your writing flow — built for content professionals.

## Target Market
Freelance content writers, copywriters, and content marketing teams at SMBs who produce written content daily and need quick, reliable word lookups.

## Problem
Content writers constantly context-switch to browser tabs for word definitions, correct usage, and pronunciation guides, breaking their writing flow. Free online dictionaries are cluttered with ads and surface-level definitions. Writers working on specialized topics need authoritative, nuanced definitions that consumer dictionary sites don't prioritize.

## Solution
A distraction-free web app (and browser extension in a later version) where content writers type a word and instantly see its definitions, part of speech, pronunciation, example sentences, and etymology — with a clean interface optimized for reading speed and focus.

## Core Features (MVP)
- Instant word lookup with definitions grouped by part of speech
- Phonetic pronunciation with audio playback
- Example sentences from Merriam-Webster's editorial corpus
- Etymology and word origin panel
- Personal word list to save lookups for vocabulary building

## API Used
- Merriam-Webster Dictionary API — provides authoritative definitions, pronunciation audio, part-of-speech classifications, example sentences, and etymologies for the full English lexicon

## Monetization
Freemium — 50 lookups/day free; Pro at $7/month for unlimited lookups, saved word list, and daily vocabulary digest email.

## Tech Stack Suggestion
Next.js + Supabase + Resend

## MVP Scope
In scope: word lookup, definitions, pronunciation audio, example sentences, etymology, saved word list. Out of scope: browser extension, contextual right-click lookup, thesaurus/synonym integration, offline mode in v1.
