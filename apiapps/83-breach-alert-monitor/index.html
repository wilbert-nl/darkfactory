How k-Anonymity Protects You

1

Your password is SHA-1 hashed entirely in your browser using the Web Crypto API — it never leaves your device.

2

Only the first 5 characters of the 40-character hash are sent to the HaveIBeenPwned API.

3

The API returns hundreds of hash suffixes starting with those 5 chars — masking which one is yours.

4

Your browser checks locally if your full hash appears in the list. The server never learns your password.
